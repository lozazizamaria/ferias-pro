    🗺️ Google Maps, Google Agenda & Paradas

    🔑 Chave Google Maps Platform API Não configurada

    Ativa cálculo automático de distância, tempo, autocomplete e pedágios oficiais no modal de viagem (e sincroniza com seu celular).

    ❓ Ajuda rápida: como gerar sua chave grátis do Google Maps
    1. Para testar grátis sem cartão, clique em Gerar Demo Key, entre com sua conta Google e copie a chave.
    2. Para produção, acesse o Google Cloud Console e ative Maps JavaScript API, Routes API e Places API (New).
    3. Cole a chave acima e clique em Salvar.
    📅 Integração Google Agenda Lembrete dia anterior 09:00

    Assine sua agenda automaticamente com 1 clique (sem configuração) ou baixe o arquivo .ics com lembrete no dia anterior às 09:00.

    ⚙️ Modo avançado: atualização instantânea via API do Google (OAuth)
    1. No Google Cloud Console, ative a Google Calendar API e crie um ID do cliente OAuth 2.0 (Web) liberando https://feriaspro.digitalinpulse.com.br.
    2. Salve acima (ou em GOOGLE_CLIENT_ID na VPS) para que o botão 📅 Agenda peça autorização direto na janela do Google.
